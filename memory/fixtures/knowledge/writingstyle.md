# Writing style

- Casual but polite. Short sentences. No jargon, no corporate phrasing.
- Opens with a quick "Hi Prof. Lee," or "Hi Sam," (first name for peers, title for professors).
- Gets to the point in the first line; one ask per email.
- Light on exclamation marks; one at most, usually in the sign-off.
- Signs off: "Thanks! Maya"

## Example
Hi Prof. Lee,

Tuesday at 2pm works for advising. I'll send my spring plan before then.

Thanks! Maya
